# ユーザーガイド

## 画面上部の表示（最初に確認）

ヘッダーの色つきの表示で、いま見ているデータの種類が分かります（スクロールしても残ります）。

| 表示 | 意味 |
|---|---|
| 緑「実データ表示中 — 楽天・Yahoo!・eBay」 | 3サイトの実際の商品を表示中（データソース「まとめて」） |
| 緑「実データ表示中 — 楽天市場」 | 楽天市場の実際の商品を表示中（データソース「楽天市場のみ」） |
| 黄「デモ表示中 — サンプル/見本データ」 | 操作確認用のサンプル、または楽天に接続できず見本データを表示中 |
| 青「楽天市場モード — 検索すると接続します」 | 楽天市場を選んだ直後（まだ検索していない） |

- 検索欄の下の「データソース」で `まとめて（楽天・Yahoo!・eBay）`・`楽天市場のみ`・`サンプルデータ` を切り替えます。
- 楽天市場に接続できないとき（設定前・設定の誤り・通信できない・応答が遅い・アクセス集中など）は、
  検索結果の上に理由が表示され、見本データに切り替わります。見本データのカードには `見本データ（実在しない商品）` と表示されます。
- 検索中はボタンが「検索中…」になり、二重に検索されません。日本語入力の変換確定の Enter では検索しません。

## 相場一覧（サイト別の価格帯）

検索すると、結果の上に「相場一覧」が出ます。サイトごとの最安〜最高を**同じ目盛りの横棒**で並べるので、どこが安いかが一目で分かります（白い縦線は中央値、「最安」は一番安いサイト）。

- 楽天市場・Yahoo!ショッピング・eBay は検索結果から自動で集計します（eBay はドル円レートで円換算）。
- 付属品・まとめ売りなど、全体の中央値から大きく外れた価格（35%未満・3倍超）は価格帯から自動で除き、黄色の帯でお知らせします。
  カードにも「相場より大幅に安い（付属品等の可能性）」と表示されます。「含めて表示する」で元に戻せます。
- メルカリ・ヤフオク・ラクマ・Amazon は自動取得しません。次のどちらかで同じ棒に並べます。
  - **貼り付けで一括取り込み**: 行の「開く」で検索ページを開き、すべて選択→コピーして、行の貼り付けボタンから貼り付けて「○件を取り込む」。
    クーポン・ポイント・送料の金額は自動で除きます。「検索表示から推定」と表示され、× でまとめて消せます（検索結果の一覧には出しません）。
  - **1件ずつ入力**: 見た価格を入力して「＋」。「手動追加」のカードとしても一覧に入り、比較に追加できます。

## まとめて開く（画面分割）

検索ショートカットで、チェックしたサイト（最初はメルカリ・ヤフオク・ラクマ・Amazon）を「まとめて開く」で**画面の右側に格子状に並べた別ウィンドウ**で開きます。
このツールを画面の左側（3分の1ほど）に寄せておくと、相場一覧を見ながら各サイトを確認し、ページをコピーしてそのまま貼り付けられます。
相場一覧の各行の「開く」も同じ位置のウィンドウで開き、押し直しても同じウィンドウを使い回します。

- 初回はブラウザがウィンドウをブロックすることがあります。アドレスバー右端のポップアップのアイコンから、このサイトを「許可」してもう一度押してください。
- 各サイトは他サイトへの埋め込みを禁止しているため、アプリの画面の中には表示しません。

## 検索結果の絞り込み・並べ替え

- 結果の上のボタンで、サイトごとの件数を確認し、押すとそのサイトだけに絞り込めます。設定していない・失敗したサイトは「未表示」と表示され、理由が相場一覧とメッセージ欄に出ます。
- 「並べ替え」で安い順・高い順にできます（ドル建ても円換算で比べます）。

## できること

- 商品名・型番・JAN・URL を入れて「まとめて探す」（楽天・Yahoo!ショッピング・eBay を同時に検索。JANコードは Yahoo! では JAN 検索になります）
- 画像つき価格カードで比較し、「比較に追加」で比較ボードへ集める（最大50件、ページを閉じても残ります）
- 比較ボードの価格をワンタップで利益計算へ反映（反映元のカードが価格欄の下に表示されます）
- 「元ページを見る」で出典を直接確認
- 「手動で追加」でカードを登録（URL・タイトル・価格・通貨（円/ドル）・送料・状態・画像URL・メモ）
- 相場一覧でサイトごとの価格帯を一目で比較。メルカリ等は見た価格を入力して並べる
- 検索ショートカットでメルカリ・ヤフオク・ラクマ・Amazon などの検索ページを開く（まとめて画面分割で開ける）
- テーマ切り替え（4種類）
- 比較カードの CSV 出力
- リサーチ履歴の保存・再開・削除（最大20件）
- ひとことメモ（入力内容から赤字・薄利・送料未入力などの注意点を自動で表示）

## 基本の流れ

1. 検索欄に商品情報を入力して「まとめて探す」
2. 気になるカードを「比較に追加」
3. 比較ボードの「この価格を仕入れに使う / 販売に使う」を押す
4. 利益見込み計算で送料・手数料率を入れて確認
5. 「元ページを見る」で実際の価格・送料・状態を確認
6. 必要に応じて CSV 出力・履歴保存

比較ボードに入れたカードは、新しく検索しても消えません。検索語を変えながら、気になるものだけを残していけます。
検索欄の「×」は検索語と検索結果だけを消し、比較ボードと利益設定は残します。

## カードの出どころラベル

| ラベル | 意味 |
|---|---|
| `公式API取得` | 楽天市場・Yahoo!ショッピング・eBay の公式な仕組み（API）から取得した実データ |
| `検索表示から推定` | 外部サイトの検索表示をもとにした参考値 |
| `検索リンク` | 外部の検索ページを開くためのリンク |
| `手動追加` | 自分で入力したカード |

## 手動追加のコツ

- URL だけ入れれば追加できます。サイト名は URL から自動で入ります。
- 価格は `¥12,800`・`１２，８００円`・`1.5万円`・`2万5千円`・`$499.99` のように書けます。
  `12,800〜15,000円` のように数字が複数ある書き方は、誤った計算を防ぐため読み取りません（「価格不明」になります）。
- 同じ URL のカードがすでにあるときは注意が表示されます（そのまま追加もできます）。
- `http`・`https` 以外の URL は登録できません。画像 URL は `https` のみです。

## 利益見込みの計算

- 利益 = 販売価格 − 手数料 − 仕入れ価格 − 送料
- 手数料は「販売価格 × 手数料率」で、1円未満は切り捨てます（主要フリマと同じ扱い）。
- 金額欄には全角数字やカンマ付き（`１２，８００`）も入力できます。数字として読めない入力はエラー表示になり、計算には使いません。
- 取引ごとの固定手数料・消費税・関税は含まれません。該当する場合は送料や仕入れ価格に足してください。
- ドル建てのカードがあると「ドル円レート」欄が出ます。レートが0のときは換算できないため、価格反映ボタンは押せません。

## CSV 出力の中身

比較ボードのカードごとに、商品名・サイト名・データ種別（実データ／サンプルデータ／見本データ）・出どころ・価格表示・価格・通貨・
送料・状態・信頼度（高/中/低）・元URL・メモ・取得日時（日本時間）を出力します。
最後に、生成日時・データソース・検索状態・警告・利益設定・利益見込みのまとめが付きます。

- Excel で文字化けしない形式（BOM 付き UTF-8）です。
- `=` `+` `-` `@` で始まる文字は、表計算ソフトが数式として実行しないよう先頭に `'` を付けます（金額の数値はそのまま出力します）。

## リサーチ履歴

- 最大20件まで保存でき、超えると古い履歴から消えます。
- 保存時のデータソース・検索状態も一緒に記録されます。「再開」は保存時の結果を戻すだけで、再検索はしません。
- ブラウザの保存容量がいっぱいのときは保存に失敗し、画面にお知らせが出ます。不要な履歴を削除してください。
- 別のタブで保存した履歴も自動で反映されます。

## 使いやすさへの配慮

- キーボード（Tab / Enter / Esc）だけで操作でき、フォーカス位置が枠線で見えます。
- ボタンなどはスマホで押しやすい大きさ（高さ44px以上）にしています。
- OS の「視差効果を減らす」「透明度を下げる」設定に合わせて、動きや透け感を控えます。
- スマホでは右側のパネルが下に並びます。

## 注意点

- 利益見込み・検索表示由来の価格は推定値です。必ず元ページで最終確認してください。
- ひとことメモは決まったルールによる注意喚起で、判断を保証するものではありません。
