# 最初にお読みください — 相場カード比較ボード

ご購入ありがとうございます。このファイルでは、届いたファイルの中身と、使い始めるまでの道順をまとめています。
専門知識がなくても、上から順に読めば進められるようにしています。

## このツールでできること

- 商品名・型番・JAN・URL から、楽天市場・Yahoo!ショッピング・eBay の価格候補をまとめて探し、画像つきのカードで見比べる
- サイトごとの価格帯を同じ目盛りの横棒で並べた「相場一覧」で、どこが安いかを一目で比べる
- 気になるカードを「比較ボード」に集めて、仕入れ・販売価格・送料・手数料から利益の見込みを出す
- メルカリ・ヤフオク・ラクマ・Amazon は、「まとめて開く（画面分割）」で検索ページを並べて開き、見た価格を相場一覧に入力する
- 比較した結果を CSV（Excel で開けるファイル）に書き出す・履歴として保存して後で再開する
- 楽天市場・Yahoo!ショッピング・eBay は、各社の公式な仕組み（API）で実際の商品と価格を表示する（キーを設定したサイトのみ）

表示される価格は参考値です。購入・出品の前に、必ず元のページで価格・送料・状態を確認してください。

## 使い始め方（3つから選べます）

### A. まず触ってみたい（パソコンの知識は不要）

`app-static/` フォルダを、Cloudflare Pages の「直接アップロード」にドラッグ＆ドロップするだけで公開できます。
楽天・Yahoo!・eBay は「見本データ」で表示されます（相場一覧への価格入力・まとめて開く・手動追加・利益計算・CSV・履歴はすべて使えます）。
手順: [`DEPLOY_GUIDE.md` の「かんたん公開」](deployment-guide.md#かんたん公開楽天の実データなし)

### B. 楽天・Yahoo!・eBay の実データも使いたい（推奨）

Cloudflare Workers に公開し、使うサイトのキーを設定します。コマンドを数回入力する作業があります。
手順: [`DEPLOY_GUIDE.md` の「Workers 版で公開」](deployment-guide.md#workers-版で公開楽天の実データあり推奨)

### C. 自分のパソコンで動かしたい・改造したい

Node.js 22 を入れて `source/` フォルダで動かします。
手順: [`source/docs/setup-guide.md`](setup-guide.md)
