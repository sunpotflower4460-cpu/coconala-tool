# 最初にお読みください — 相場カード比較ボード

ご購入ありがとうございます。このファイルは「③詳しい資料」の案内です。
**アプリを使うだけなら、このフォルダは開かなくて大丈夫です。** 届いた `②マニュアル.pdf` の手順どおりにアプリを入れてください。

## このアプリでできること

- 商品名・型番・JAN を入れて「まとめて探す」を押すだけで、楽天市場・Yahoo!ショッピング・eBay の商品を画像つきで並べる
- 同時に、メルカリ・ヤフオク・ラクマ・Amazon の検索結果をアプリの右側のタブに開く
- 「値段を取り込む」を押すと、右側に表示中のページから値段と商品リンクを読み取り、同じ一覧に並べる
- サイトごとの値段の幅（相場一覧）、比較ボード、利益の見込み、保存、CSV 書き出し

表示される価格は参考値です。購入・出品の前に、必ず元のページで価格・送料・状態を確認してください。

## 使い方の選び方

### A. アプリを使う（おすすめ・知識は不要）

`②マニュアル.pdf` の「2. インストールする」「3. 最初の設定」の順に進めてください。

### B. アプリを入れずにブラウザだけで使う

`ブラウザ版（自動取得なし）.html` をダブルクリックします。楽天・Yahoo!・eBay の自動取得と、右側のタブ・値段の取り込みはありません
（各サイトの検索ページを開いて、価格を貼り付け・入力して比較します）。

### C. Web 版をインターネットに公開したい

- 自動取得なしでよければ、`app-static/` を Cloudflare Pages 等にドラッグ＆ドロップするだけです:
  [`DEPLOY_GUIDE.md` の「かんたん公開」](deployment-guide.md#かんたん公開楽天の実データなし)
- 楽天・Yahoo!・eBay の自動取得も使うなら Cloudflare Workers に公開します:
  [`DEPLOY_GUIDE.md` の「Workers 版で公開」](deployment-guide.md#workers-版で公開楽天の実データあり推奨)

### D. 改造したい

Node.js 22 を入れて `source/` フォルダで動かします。デスクトップアプリは `npm run desktop` で起動、`npm run dist:desktop:mac` / `npm run dist:desktop:win` でインストーラーを作れます。
手順: [`source/docs/setup-guide.md`](setup-guide.md)
