# 公開後の確認

## 自動チェック（推奨）

公開URLに対して、画面表示・検索・比較・利益計算・履歴・レイアウト（PC/スマホ幅）・セキュリティ設定を自動で確認します。

```bash
npx playwright install chromium        # 初回のみ
E2E_BASE_URL=https://あなたの公開URL npm run e2e:postdeploy
```

Windows の PowerShell では次のように実行します。

```powershell
$env:E2E_BASE_URL="https://あなたの公開URL"; npm run e2e:postdeploy
```

すべて `passed` なら合格です。失敗したときは表示されたテスト名と、`test-results/` に保存される画面写真を確認してください。

## 目で確認すること（自動化できない項目だけ）

- [ ] データソースを「まとめて（楽天・Yahoo!・eBay）」にして、実際に扱う商品名で1回検索し、ヘッダーが緑「実データ表示中」になり、
      絞り込みボタンにキーを設定したサイトの件数が出る
- [ ] 各サイトの商品を1つずつ「元ページを見る」で開き、価格が大きく違わない
- [ ] 「まとめて開く（画面分割）」でメルカリ等が並んで開く（初回はポップアップの許可が必要）
- [ ] 手持ちのスマホで公開URLを開き、検索と「比較に追加」ができる

キーを設定していないサイトは「未表示」と、相場一覧に「連携がまだ設定されていません」と表示されれば正常です。
