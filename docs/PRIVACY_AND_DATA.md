# データの扱いについて

## 基本方針

本ツールには、利用者の個人情報や検索内容を制作者のサーバーへ送る仕組みはありません。
アクセス解析・広告のためのスクリプトも入っていません。

## デスクトップアプリで保存されるもの

- 比較ボード・利益設定・テーマ・リサーチ履歴は、アプリ内（このパソコンのユーザーフォルダ）にだけ保存されます。
- 楽天・Yahoo!・eBay のキーは、OS の暗号化の仕組み（Mac はキーチェーン、Windows は資格情報の保護）で暗号化して、同じくこのパソコンにだけ保存します。
  画面（アプリの表示部分）にはキーの値を渡さず、「設定済みかどうか」だけを伝えます。
- 右側のタブで開いたサイトのログイン状態（Cookie 等）は、アプリ専用の保存場所に残ります（いつものブラウザとは別です）。
- アプリを削除しても保存データは残ります。完全に消すときは、Mac は `~/Library/Application Support/SobaCardBoard`、
  Windows は `%APPDATA%\SobaCardBoard` のフォルダを削除してください。

### デスクトップアプリの通信

| 通信先 | いつ | 送られる内容 |
|---|---|---|
| 楽天ウェブサービス・Yahoo!デベロッパーネットワーク・eBay | 「まとめて探す」・キーのテストのとき | 検索語・件数と、利用者ご自身のキー（アプリから各社へ直接送ります。制作者は経由しません） |
| メルカリ・ヤフオク・ラクマ・Amazon | 「まとめて探す」で右側のタブを開くとき | 通常のページ閲覧と同じ |
| 商品画像の配信元・Google Fonts | 画面を表示したとき | 画像・書体の取得 |

「値段を取り込む」で読み取った値段・リンクは、アプリの中だけで使い、どこにも送りません。

## Web 版：ブラウザ内に保存されるもの

- 比較ボード・利益設定・テーマ・データソースの選択・リサーチ履歴（最大20件）は、
  **お使いのブラウザの localStorage** にだけ保存されます。
- 別の端末・ブラウザからは見えません。ブラウザの「閲覧データを削除」で消えます。
- 検索結果そのもの（比較ボードに入れていないカード）は、ページを閉じると消えます（履歴に保存した場合を除く）。

## Web 版：外部との通信

| 通信先 | いつ | 送られる内容 |
|---|---|---|
| 購入者自身の Cloudflare Workers（`/api/rakuten`・`/api/yahoo`・`/api/ebay`） → 楽天ウェブサービス・Yahoo!デベロッパーネットワーク・eBay | 楽天市場・まとめて検索のとき | 検索語・件数。各社のキーはサーバー側で付与され、ブラウザには出ません |
| Google Fonts（fonts.googleapis.com / fonts.gstatic.com） | ページを開いたとき | 文字の書体データの取得（一般的なWebサイトと同様に、閲覧者のIPアドレス等が Google に届きます） |
| 商品画像の配信元（楽天の画像サーバー、手動追加で指定した画像URL 等） | カードを表示したとき | 画像の取得（参照元URLは送らない設定です） |
| メルカリ・ヤフオク等の外部サイト | 利用者が検索リンク・元ページリンク・「まとめて開く」を押したとき | 通常のページ閲覧（アプリは中身を読み取りません） |

- 楽天市場モードの通信は、購入者ご自身の Cloudflare アカウント上で動きます。制作者は経由しません。
- Cloudflare Workers の標準ログ機能（`wrangler.jsonc` の `observability`）が有効なため、`/api/rakuten` へのアクセス（検索語を含むURL）が
  購入者の Cloudflare アカウントのログに一定期間残ります。不要な場合は `observability.enabled` を `false` にしてください。

## APIキーについて

- Web 版では、楽天・Yahoo!・eBay のキーは Cloudflare Workers のシークレット（サーバー側）にだけ保存します。デスクトップアプリでは上のとおりパソコン内に暗号化して保存します。
- 画面（ブラウザに配信されるファイル）・納品物・CSV・履歴には含まれません。納品前の自動チェックで、
  ビルド済みファイルにキーらしき値が無いことを確認しています（`QUALITY_REPORT.md`）。

## CSV 出力

CSV はブラウザ内で作られ、利用者の端末に直接保存されます。サーバーは経由しません。

## 購入者ご自身の責任範囲

- 本ツールを購入者のサービスとして公開・運用する場合、そのサービスでの個人情報保護法等の遵守は購入者の責任で行ってください
  （`TERMS.md`「5. 保証なし・免責」も参照）。
- 表示される価格・在庫は各サイト・楽天の公開情報に基づくもので、本ツールが独自に収集・保管するものではありません。
