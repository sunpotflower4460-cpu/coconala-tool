# データの扱いについて

## 基本方針

本ツールには、利用者の個人情報や検索内容を制作者のサーバーへ送る仕組みはありません。
アクセス解析・広告のためのスクリプトも入っていません。

## ブラウザ内に保存されるもの

- 比較ボード・利益設定・テーマ・データソースの選択・リサーチ履歴（最大20件）は、
  **お使いのブラウザの localStorage** にだけ保存されます。
- 別の端末・ブラウザからは見えません。ブラウザの「閲覧データを削除」で消えます。
- 検索結果そのもの（比較ボードに入れていないカード）は、ページを閉じると消えます（履歴に保存した場合を除く）。

## 外部との通信

| 通信先 | いつ | 送られる内容 |
|---|---|---|
| 購入者自身の Cloudflare Workers（`/api/rakuten`） → 楽天ウェブサービス | 楽天市場モードで検索したとき | 検索語・件数。楽天のキーはサーバー側で付与され、ブラウザには出ません |
| Google Fonts（fonts.googleapis.com / fonts.gstatic.com） | ページを開いたとき | 文字の書体データの取得（一般的なWebサイトと同様に、閲覧者のIPアドレス等が Google に届きます） |
| 商品画像の配信元（楽天の画像サーバー、手動追加で指定した画像URL 等） | カードを表示したとき | 画像の取得（参照元URLは送らない設定です） |
| メルカリ・ヤフオク等の外部サイト | 利用者が検索リンク・元ページリンクを押したとき | 通常のページ閲覧 |

- 楽天市場モードの通信は、購入者ご自身の Cloudflare アカウント上で動きます。制作者は経由しません。
- Cloudflare Workers の標準ログ機能（`wrangler.jsonc` の `observability`）が有効なため、`/api/rakuten` へのアクセス（検索語を含むURL）が
  購入者の Cloudflare アカウントのログに一定期間残ります。不要な場合は `observability.enabled` を `false` にしてください。

## APIキーについて

- 楽天のアプリID・アクセスキーは、Cloudflare Workers のシークレット（サーバー側）にだけ保存します。
- 画面（ブラウザに配信されるファイル）・納品物・CSV・履歴には含まれません。納品前の自動チェックで、
  ビルド済みファイルにキーらしき値が無いことを確認しています（`QUALITY_REPORT.md`）。

## CSV 出力

CSV はブラウザ内で作られ、利用者の端末に直接保存されます。サーバーは経由しません。

## 購入者ご自身の責任範囲

- 本ツールを購入者のサービスとして公開・運用する場合、そのサービスでの個人情報保護法等の遵守は購入者の責任で行ってください
  （`TERMS.md`「5. 保証なし・免責」も参照）。
- 表示される価格・在庫は各サイト・楽天の公開情報に基づくもので、本ツールが独自に収集・保管するものではありません。
