# プラン内容とサポートポリシー

## プラン内容

| 項目 | ライト | スタンダード | プレミアム |
|---|---|---|---|
| ソースコード一式・静的版（`app-static/`） | ✓ | ✓ | ✓ |
| タイトル・配色のカスタマイズ | ✓ | ✓ | ✓ |
| Cloudflare Workers への公開作業 | — | ✓ | ✓ |
| 楽天市場・Yahoo!ショッピング・eBay の実データ連携（購入者のキーの設定支援） | — | ✓ | ✓ |
| 表示項目・CSV列・利益計算ロジックの調整 | — | — | ✓ |
| マニュアル | 同梱文書 | 同梱文書＋簡易マニュアル | 同梱文書＋詳細マニュアル |
| サポート期間 | なし（納品時の動作確認まで） | 納品後3日間 | 納品後7日間 |

料金・日数はご購入時のココナラ出品ページの記載を正とします。本表と食い違う場合は出品ページ・購入時のやり取りを優先します。

## 連絡方法

ココナラのメッセージ機能からご連絡ください。

## サポート対象

- 納品物のビルド・起動・公開に関するエラー
- 本ツール固有の不具合（表示崩れ、計算ミス、明らかなバグ）
- 同梱文書の手順どおりに進まない場合の確認

## サポート対象外

- ブラウザ・OS・端末固有の設定問題
- 楽天・Yahoo!・eBay のキーの取得手続きそのもの（取得方法のご案内はします）
- Cloudflare・その他ホスティングサービスのアカウント作成・障害対応
- 購入後のカスタマイズ要望（機能追加・デザイン変更等は別途お見積り）
- 公式の検索APIが無いサイト（メルカリ・ヤフオク・ラクマ等）の自動取得（規約違反になるため対応しません）
- 第三者のAPI・サービスの仕様変更・障害
- 税務・法務・輸出入規制に関するご質問

## 追加見積りの対象

- タイトル・配色以外のデザイン変更、機能追加
- 上記3サイト以外の公式API連携（例: Amazon Creators API。利用条件の確認が必要）、クラウド保存、ログイン、多言語対応
- プレミアムプランの範囲を超える CSV 列・利益計算ロジックの調整

## 返金・キャンセル

返金・キャンセルの扱いは、ご購入時にご案内した条件に従います。個別の判断が必要な場合は、まずココナラのメッセージ機能でご相談ください。
