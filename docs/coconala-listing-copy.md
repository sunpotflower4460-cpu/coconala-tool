# ココナラ掲載文

対象バージョン: v1.0.0-beta.2（出品ページへ転記する前に、最新の `package.json` のバージョンと一致しているか `npm run verify:release` で確認されます）

## サービスタイトル

ボタン1つで7サイトの相場を並べる、物販リサーチ用アプリを提供します

## サブタイトル案

楽天・Yahoo!・eBay は画像つきで自動表示、メルカリ・ヤフオク・ラクマ・Amazon も同じ画面で。Windows / Mac 対応。

## 売り文句

> 商品名を入れて「まとめて探す」を押すだけ。楽天市場・Yahoo!ショッピング・eBay の商品が画像つきで並び、メルカリ・ヤフオク・ラクマ・Amazon の検索結果も同じ画面の右側に開きます。「値段を取り込む」を押せば、すべての値段を安い順に1つの一覧で比較。利益見込み・保存・CSV まで、このアプリだけで完結します。

## サービス説明文案

物販・せどり・越境販売向けの、相場リサーチ補助アプリ（Windows / Mac）をお渡しします。

- 「まとめて探す」1回で、楽天市場・Yahoo!ショッピング・eBay の商品を画像つきで表示（公式API・ご自身の無料キーで取得）
- 同時に、メルカリ・ヤフオク・ラクマ・Amazon の検索結果をアプリの右側のタブに表示（ページを切り替えずに見比べられます）
- 「値段を取り込む」1回で、右側のページの値段と商品リンクを一覧に追加（コピペ・手入力は不要）
- サイトごとの値段の幅を1枚のグラフで比較。付属品など相場から外れた値段は自動で注意表示
- 比較ボード・利益見込み（仕入れ/販売/送料/手数料）・保存・CSV 出力
- はじめての設定は、アプリ内の案内どおりにコピー＆貼り付けするだけ（貼ったキーはその場でテスト）
- 画面写真つきの「かんたん操作マニュアル」（インストールから困ったときまで）付き

表示される価格は参考値として明示し、元ページですぐ確認できるようにしています。

## できること

- 楽天市場・Yahoo!ショッピング・eBay の公式APIによる同時検索と画像つき表示（購入者ご自身の無料キーで取得。eBay は円換算）
- メルカリ・ヤフオク・ラクマ・Amazon の実際の検索ページを、アプリ内のタブで表示
- 表示中の検索ページから、値段と商品リンクをボタン1つで一覧に取り込み（画像・説明文は読み取りません）
- サイト別の値段の幅を同じ目盛りで並べる「相場一覧」と、安い順の一覧
- 比較ボード、利益見込み計算、リサーチ履歴（最大20件）、CSV 出力
- 実データ（公式API）・画面からの取り込み・手入力の区別を、カード・比較ボード・CSV のすべてで明示（実在しない商品は表示しません）
- キーはパソコン内に暗号化して保存（制作者のサーバーは経由しません）

## できないこと（誤解を避けるために）

- メルカリ・ヤフオク・ラクマ・Amazon の自動巡回・大量取得・画像の取得はしません（利用者が押したときに、表示中の1ページから値段とリンクだけを読みます）
- 各サイトの画面が変わると、取り込める件数が減ることがあります（探す・見る・元ページへ飛ぶは使えます）
- 表示価格は確定価格ではありません。最終判断は必ず元ページで確認してください
- 「確実に利益が出る商品」を自動で発見する機能はありません。利益見込みは推定値です
- 最安値の保証はしません
- 放置しているだけで自動的に稼げる/せどりが完結する機能ではありません（あくまでリサーチ補助ツールです）
- 税務・法務上の判断はできません。取引・申告等はご自身の責任で行ってください
- スマートフォン用のアプリはありません（パソコン用。スマホでは Web 版を別途公開して使えます）

## よくある質問

**Q. メルカリ・ヤフオクの値段も一覧に出ますか？**
A. はい。「まとめて探す」でアプリの右側に各サイトの検索結果が開き、「値段を取り込む」を押すと値段と商品リンクが一覧に加わります（画像は取り込みません）。

**Q. パソコンに詳しくなくても使えますか？**
A. はい。インストールからキーの登録まで、マニュアルとアプリ内の案内どおりにクリック・コピー＆貼り付けするだけです。

**Q. 表示される価格は正確ですか？**
A. 参考値です。価格・在庫は変動するため、購入・出品前に必ず元ページでご確認ください。

**Q. データやキーはどこに保存されますか？**
A. すべてお使いのパソコンの中に保存され、制作者のサーバーには送信されません。詳細は `docs/PRIVACY_AND_DATA.md` を参照してください。

**Q. スマホで使えますか？**
A. アプリはパソコン用です。スマホからも使いたい場合は、Web 版を公開して使えます（プレミアムプラン、または同梱の手順でご自身で公開）。

**Q. 納品後にカスタマイズを依頼できますか？**
A. 可能です。標準プランの範囲を超えるご要望は、要件確認のうえ別途お見積りいたします（上記「追加見積の境界」参照）。
