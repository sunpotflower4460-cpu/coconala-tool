# クイックスタート（5分で試す）

## 1. 開く

公開したURL（または制作者から共有されたURL）をブラウザで開きます。
まだ公開していない場合は [`README_FIRST.md`](README_FIRST.md) の「使い始め方」を見てください。

## 2. 探す

1. 検索欄に商品名（例: `PS5`）を入れて「まとめて探す」を押します。
2. 画像つきの価格カードが並びます。カードの上のラベルで、どこから来た情報かが分かります。
   - `公式API取得`: 楽天市場の実データ
   - `検索表示から推定` / `検索リンク`: 外部サイトの検索ページ由来（参考値）
   - `手動追加`: 自分で登録したもの
   - `サンプルデータ` / `見本データ`: 操作確認用（実在しない商品を含みます）

## 3. 比べる・利益を見る

1. 気になるカードの「比較に追加」を押すと、右側（スマホでは下）の比較ボードに入ります。
2. 比較ボードの「この価格を仕入れに使う」「この価格を販売に使う」を押すと、利益計算に反映されます。
3. 送料・手数料率を入れると、利益の見込みと利益率が出ます（手数料は1円未満切り捨て）。

## 4. 元ページで確かめる

「元ページを見る」で実際のページを開き、価格・送料・状態を必ず確認してください。

## 5. 残す

- 「比較中カードをCSV出力」で Excel で開けるファイルに保存できます。
- 「リサーチ履歴」に名前を付けて保存すると、あとで「再開」できます（最大20件、このブラウザ内に保存）。
- 比較ボードは、ページを閉じても次に開いたときに残っています。

## 楽天の実データが出ないとき

ヘッダーが「デモ表示中」のままなら、楽天の設定がまだです。
[公開ガイドの「Workers 版で公開」](deployment-guide.md#workers-版で公開楽天の実データあり推奨) の手順3・4を行ってください。

## できないこと

- 楽天市場以外（メルカリ・ヤフオク・Amazon 等）の自動取得はしません（検索リンク＋手動追加）
- 表示価格は確定価格ではありません。消費税・関税・固定手数料は利益計算に含まれません
