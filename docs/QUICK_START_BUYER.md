# クイックスタート（5分で試す）

## 1. 開く

公開したURL（または制作者から共有されたURL）をブラウザで開きます。
パソコンで使うだけなら、ZIP の一番上にある `①ツールを開く.html` をダブルクリックしてください。公開したい場合は [`README_FIRST.md`](README_FIRST.md) の「使い始め方」を見てください。

## 2. 探す

1. データソースを「まとめて（楽天・Yahoo!・eBay）」にして、検索欄に商品名（例: `PS5`）を入れて「まとめて探す」を押します。
2. 画像つきの価格カードが並びます。カードの上のラベルで、どこから来た情報かが分かります。
   - `公式API取得`: 楽天市場・Yahoo!ショッピング・eBay の実データ
   - `検索表示から推定` / `検索リンク`: 外部サイトの検索ページ由来（参考値）
   - `手動追加`: 自分で登録したもの

## 3. 相場を一目で見る

結果の上の「相場一覧」に、サイトごとの価格帯が同じ目盛りの横棒で並びます。
メルカリ・ヤフオク・ラクマ・Amazon は、ツールを画面の左に寄せて「まとめて開く（右側に画面分割）」で各サイトを右に並べ、
ページを「すべて選択→コピー」して相場一覧の貼り付けボタンから貼ると、価格がまとめて同じ棒に並びます。

## 4. 比べる・利益を見る

1. 気になるカードの「比較に追加」を押すと、右側（スマホでは下）の比較ボードに入ります。
2. 比較ボードの「この価格を仕入れに使う」「この価格を販売に使う」を押すと、利益計算に反映されます。
3. 送料・手数料率を入れると、利益の見込みと利益率が出ます（手数料は1円未満切り捨て）。

## 5. 元ページで確かめる

「元ページを見る」で実際のページを開き、価格・送料・状態を必ず確認してください。

## 6. 残す

- 「比較中カードをCSV出力」で Excel で開けるファイルに保存できます。
- 「リサーチ履歴」に名前を付けて保存すると、あとで「再開」できます（最大20件、このブラウザ内に保存）。
- 比較ボードは、ページを閉じても次に開いたときに残っています。

## 実データが出ないとき

ヘッダーが「自動取得できませんでした」になり、理由に「設定」とあれば、各サイトのキーの設定がまだです。
[公開ガイドの「Workers 版で公開」](deployment-guide.md#workers-版で公開楽天の実データあり推奨) の手順3・4を行ってください。

## できないこと

- メルカリ・ヤフオク・ラクマ・Amazon の自動取得はしません（公式の検索APIが無いため。検索ページを開いて見た価格を入力します）
- 表示価格は確定価格ではありません。消費税・関税・固定手数料は利益計算に含まれません
