# クイックスタート（5分で試す）

画面写真つきの手順は `②マニュアル.pdf` にあります。ここでは流れだけをまとめます。

## 1. アプリを入れる

お使いのパソコンに合う `①アプリ（…用）` をダブルクリックして入れます（Windows は `.exe`、Mac は `.dmg`）。
初回に「PCが保護されました」「開発元を確認できません」と出たときの開き方は、マニュアルの「2. インストールする」にあります。

## 2. キーを登録する（あとからでも可）

初めて開くと「設定」が出ます。楽天市場・Yahoo!ショッピング（必要なら eBay）の手順どおりにキーを貼り、「保存してテスト」で「使えます」と出れば完了です。
キーが無くても、メルカリ・ヤフオク・ラクマ・Amazon の表示と値段の取り込みは使えます。

## 3. 探す（ボタン1つ）

検索欄に商品名・型番・JAN を入れて「まとめて探す」を押します。

- 楽天市場・Yahoo!ショッピング・eBay の商品が、画像つきで下の一覧に安い順に並びます
- メルカリ・ヤフオク・ラクマ・Amazon の検索結果が、右側のタブに開きます
- 検索欄のすぐ下の「サイトごとの状況」で、どのサイトの結果がどこに出ているかが分かります

## 4. 値段を取り込む（ボタン1つ）

「メルカリ・ヤフオク・ラクマ・Amazon の値段を取り込む」を押すと、右側に表示中のページから値段と商品リンクを読み取り、一覧に加えます（画像なし・「検索表示から推定」）。

## 5. 比べる・利益を見る

1. 気になるカードの「比較に追加」を押すと、右側の「比較・利益」タブに入ります。
2. 「この価格を仕入れに使う」を押し、販売価格・送料・手数料率を入れると、利益の見込みと利益率が出ます（手数料は1円未満切り捨て）。

## 6. 元ページで確かめる

カードの「元ページを見る」で、いつものブラウザに実際のページが開きます。価格・送料・状態を必ず確認してください。

## 7. 残す

右側の「保存・CSV」タブで、名前を付けて保存（あとで再開）・CSV（Excel で開けるファイル）の書き出しができます。保存したデータはこのパソコンの中だけにあります。

## できないこと

- メルカリ・ヤフオク・ラクマ・Amazon の自動巡回・画像の取得はしません（利用者が押したときに、表示中の1ページから値段とリンクだけを読みます）
- 表示価格は確定価格ではありません。消費税・関税・固定手数料は利益計算に含まれません

ブラウザ版・Web 版の使い方は [`USER_GUIDE.md`](user-guide.md) の後半にあります。
