# 既知の制限事項

## デスクトップアプリ

- 公式な仕組み（API）で自動取得するのは楽天市場・Yahoo!ショッピング・eBay です（利用者ご自身のキーで取得）。
- メルカリ・ヤフオク・ラクマ・Amazon は公式の検索APIが無い（または利用条件がある）ため、検索ページをアプリの右側のタブで表示します。
  「値段を取り込む」は、利用者がボタンを押したときに表示中の1ページから値段と商品リンクだけを読む補助機能です（画像・説明文は読まず、ページ送りや自動巡回はしません）。
  各サイトの利用規約はプログラムによる情報の取得を制限しているため、規約に沿った使い方かどうかは利用者ご自身でご判断ください（設定でサイトごとにオフにできます）。
- 取り込みは各サイトの画面の作り（商品ページへのリンクの形）に合わせています。サイトの画面が変わると、読み取れる件数が減ることがあります（探す・見る・元ページへ飛ぶは影響を受けません）。
  ログイン画面・確認画面（画像認証など）が出ているときは読み取れません。アプリが確認を突破することはありません。
- 取り込んだ値段は検索ページの表示から推定したものです（送料込みかどうか・売り切れかどうかは判定しません）。必ず元ページで確認してください。
- インストーラーには開発元の署名（Apple・Microsoft の有料証明書）が付いていません。初回に表示される確認の開き方はマニュアルの「2. インストールする」にあります。
- 自動更新はありません。新しいバージョンは、届いたインストーラーを入れ直してください（キー・保存データは残ります）。
- 楽天のアプリ登録では、このアプリの紹介ページのURLを「許可されたWebサイト」に入れます。楽天側の仕様が変わると、設定方法が変わる可能性があります。

## 共通（Web 版・ブラウザ版を含む）

- Web 版は、各サイトが他サイトへの埋め込みを禁止しているため、画面内に他サイトを表示できません
  （「まとめて開く」でツールの右側に別ウィンドウを並べ、ページをコピーして貼り付けると価格を一括で取り込めます）。
- 貼り付けで取り込んだ価格は、ページ内の「¥」「円」の金額から推定したものです（商品名との対応は取りません）。
- Web 版で実データを使うには、Cloudflare Workers 版で公開し、使うサイトのキーをサーバー側に設定する必要があります
  （[`deployment-guide.md`](deployment-guide.md)）。静的版（`app-static/`）・Vercel・GitHub Pages では自動取得をしません（価格の貼り付け・入力で比較します）。
- eBay は米国の eBay（ドル建て）を検索し、ドル円レートで円換算して比較します。送料・関税は含みません。
- Yahoo!ショッピングの公式APIは約1秒1回が上限のため、同時に多くの人が使うと一時的に表示できないことがあります。
- 楽天の新しい仕組み（2026年〜）に合わせています。楽天側の仕様変更・障害・利用上限の影響を受けることがあります。
  接続できないときは理由を表示します（実在しない商品を代わりに出すことはありません）。楽天のアプリには有効期限（約1年）があり、期限前の延長が必要です。
- 楽天は1文字の半角語を含む検索語を受け付けないため、「Nintendo Switch 2」の「2」のような語は直前の語につなげて（「Switch2」）検索します。
- 表示価格・利益見込みは参考値です。在庫・送料・状態は元ページで確認してください。
- 利益計算に取引ごとの固定手数料・消費税・関税は含まれません。手数料は1円未満切り捨てです。
- データ（比較ボード・利益設定・テーマ・履歴）は、そのパソコンのアプリ内（Web 版はブラウザ内の localStorage）にだけ保存されます。別の端末・ブラウザとは共有されず、
  ブラウザのデータ削除で消えます。ブラウザの設定で保存が禁止されている場合は、保存せずにその場でのみ使えます。
- 比較ボードは最大50件、リサーチ履歴は最大20件です。
- ログイン・課金・クラウド保存・多言語対応はありません（追加開発の対象）。
- `/api/rakuten` のレート制限（既定: 1IPあたり60秒30回）は Cloudflare の各拠点ごとに数える簡易な仕組みで、厳密な回数管理ではありません。
